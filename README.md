# المؤقت الزمني وساعة الإيقاف (Arabic Timer)

- **نقطة ادخال مقدمة**: نسخة سطح المكتب في `timer_app.py` — تطبيق Tkinter
  يعمل على ويندوز و macOS (الربط RTL) و Linux، بلا أي مكتبات خارجية:
  ```bash
  python3 timer_app.py
  ```
- **نسخة الأندرويد**: في `mobile/` (إطار Kivy + buildozer) — راجع
  [mobile/BUILD.md](mobile/BUILD.md) لمط البنا عبر GitHub Actions أو محلياً.

## الميزات

1. عدّاد تنازلي:
   - قرص دائري متدرّج الألوان حسب الوقت المتبقي.
   - ضبط الساعات/الدقائق/الثواني + أوقات جاهزة سريعة (بما فيها بومودورو 25 د).
   - مؤقتات مخصصة محفوظة بالاسم (حفظ/تشغيل/حذف بالنقر المطوّل في نسخة أندرويد).
   - تنبيه صوتي مولّد برمجياً + إمكانية التكرار التلقائي.
2. ساعة إيقاف بمه عالية (`time.perf_counter`) مع لفات وتحديد أسرع/أبطأ لفة.
3. وضع داكن/فاتح، إبقاؤ النافذة في المقدمة (سطح المكتب)، حفظ الإعدادات.
